# APRENDICE

Site de estudos para vestibulares de todo o Brasil (funciona no navegador do computador, do celular e do tablet): questões reais de prova por nível de dificuldade, resolução comentada, teoria em cartões, flashcards curtos e simulados por universidade.

- `app-atual/` — protótipo funcional (HTML estático; 4 matérias). Build: `cd app-atual && python3 design/gera_design.py`, depois abrir `app-atual/index.html` por um servidor local (`python3 -m http.server`).
- `docs/` — estado, pesquisa e histórico.
- `CLAUDE.md` — princípios do produto e mapa do código.
