## por-f003 (P01.2, peso 3)
- ANTES: Informação explícita × inferência: qual a diferença? → Explícita está escrita no texto: dá para apontar a linha. Inferência é a conclusão que o texto obriga a tirar, a partir de pistas dele, embora não a escreva.
- DEPOIS: Conclusão que o texto obriga a tirar, sem escrevê-la? → Inferência — sai das pistas do texto

  - erro comum: Chamar de inferência um palpite que o texto só permite, mas não obriga.

## por-f004 (P01.2, peso 3)
