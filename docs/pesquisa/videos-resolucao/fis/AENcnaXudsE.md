# Questão Resolvida - Força Resultante nº 02

- Canal: Questões de Vestibular
- Link: https://www.youtube.com/watch?v=AENcnaXudsE
- Duração: 6 min

## Questão(ões)
- **Assunto:** Física
- **Subtema:** Estática / Dinâmica (Forças coplanares e força resultante)
- **Resumo do enunciado:** A figura mostra três forças coplanares ($F_1 = 20\text{ N}$, $F_2 = 20\text{ N}$ com ângulos de $60^\circ$ com a horizontal, e $F_3 = 8\text{ N}$ na horizontal para a esquerda) atuando em um corpo. Pede-se para somar os itens corretos entre cinco afirmações sobre a resultante das forças.

---

## Passo a passo da resolução
1. **[01:10 - 03:51]** O professor analisa as forças $F_1$ e $F_2$ geometricamente, transladando os vetores para calcular a resultante entre eles ($F_{R12}$). Como $F_1 = 20\text{ N}$, $F_2 = 20\text{ N}$ e o ângulo total entre elas é de $120^\circ$ ($60^\circ + 60^\circ$), o professor aplica a regra do caso particular: quando duas forças de mesmo módulo formam um ângulo de $120^\circ$, a resultante tem o mesmo valor das forças. Portanto, $F_{R12} = 20\text{ N}$, apontando para a direita na horizontal.
2. **[03:55 - 04:32]** O professor calcula a força resultante total ($F_R$) combinando $F_{R12}$ ($20\text{ N}$ para a direita) com $F_3$ ($8\text{ N}$ para a esquerda). A conta é: $F_R = 20 - 8 = 12\text{ N}$, com sentido para a **direita**.
3. **[04:33 - 05:48]** O professor analisa cada item da questão (01, 02, 04, 08, 16) com base nos cálculos realizados para determinar quais são verdadeiros ou falsos.
4. **[05:49 - 06:05]** O professor soma os números associados aos itens corretos identificados ($02 + 04 + 16$) e obtém o resultado final $22\text{ N}$.

## Alternativas
- **01 (A resultante das três forças aplicadas no corpo é nula):** Julgada falsa, pois a resultante deu $12\text{ N}$ para a direita.
- **02 (A resultante das forças $F_1$ e $F_2$ é de $20\text{ N}$, na horizontal e para a direita):** Julgada verdadeira, comprovada pelo cálculo do caso particular de $120^\circ$.
- **04 (A resultante das três forças é de $12\text{ N}$, na horizontal e para a direita):** Julgada verdadeira, calculada subtraindo $20\text{ N} - 8\text{ N} = 12\text{ N}$.
- **08 (A resultante das três forças é de $12\text{ N}$, na horizontal e para a esquerda):** Julgada falsa, pois o sentido correto é para a direita.
- **16 (A resultante será nula se o corpo receber a ação de uma quarta força de $12\text{ N}$ na horizontal e para a esquerda):** Julgada verdadeira, pois adicionar uma força oposta de mesma intensidade ($12\text{ N}$ para a esquerda) anularia a resultante anterior de $12\text{ N}$ para a direita.
